# 🪐 JUPITA SHOP

**Jupita Shop** is a modern streetwear e-commerce web app where users can explore bold outfits, add them to their cart, and checkout smoothly.  
Built with **React** and **Supabase**, it blends futuristic design with African streetwear energy.

---

## ⚙️ Tech Stack
- **Frontend:** React + Vite  
- **Backend:** Supabase (PostgreSQL, Auth, Storage)  
- **State Management:** useState + LocalStorage  
- **Routing:** React Router DOM  
- **Styling:** CSS / Tailwind (optional)

---

## 🚀 Features
- View and browse streetwear collections  
- Add and remove products from cart  
- Update quantities instantly  
- Secure login via Supabase Auth  
- Checkout with name, email & location  
- Auto order processing + receipt generation
